🌈 VibeCheck 411L
Welcome to VibeCheck 411L, the ultimate interactive fidget website! Feeling bored at your desk? Stressed about a bug? Just need a digital high-five? You're in the right place.

This isn't just a webpage; it’s a mood-boosting dashboard that talks to a live Node.js API to deliver instant vibes.

🕹️ The Control Panel
The interface features a variety of interactive "fidget" triggers:

🔮 Fortune: Get a glimpse into your future (no crystal ball required).

😂 Joke: Dad jokes, puns, and high-quality comedy on demand.

😄 Happy: Boost the mood when things are going great!

🥱 Tired: For those 3 PM slumps when you've had too much coffee (or not enough).

💥 SMASH!: The ultimate digital stress ball. Click it to let it all out.

🕵️ Secret: [REDACTED] — Click at your own risk. 🫣

🚀 How It Works
This project is a full-stack experience. When you click a button:

A Fetch request is sent to the custom Node.js VibeCheck API.

The API processes your mood or request.

The response is piped directly back into your terminal-style output box.

🛠️ Installation & Setup
Want to run this locally? It's as easy as:

Clone the repo:

Bash

git clone https://github.com/your-username/vibecheck-411l.git
Start your API: Make sure your Node.js server is running so the buttons can "talk" to something!

Open index.html: Simply open the file in your favorite browser and start clicking.
